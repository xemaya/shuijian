# 安全边界

水鉴是反思与事实梳理工具，不是危机处置、心理治疗或专业咨询产品。

## 宿主先行

ChatGPT 自身安全政策始终优先。Tool 的 `safetySignal`只能把限制提高到 `support_only`或`handoff_required`，不能降低九字核心检测到的限制。

## Tool 内覆盖

- `support_only`：不调用`住、拆、断、空`。只做承接、当下安全所需事实确认、现实证据核验、具体支持选择或停止。
- `handoff_required`：停止普通反思，不挑战、不解释、不哲学化；优先现实中的可信任支持、当地急救或报警服务。
- 九字核心返回安全候选时，不能用普通建议覆盖它。

## 不确定时

- 现实危险线索不清：先`照`，只确认当下安全所需的一件事实。
- 用户不愿被挑战：转`接`或`止`，不要变换说法继续拆。
- 真实约束明确：转`验`或`生`，不要证明墙是假的。
- 深入是否有价值不清：选`止`。

不要承诺九字核心已覆盖宿主所有自然语言回复；只有实际 Tool 调用才经过核心安全覆盖。
